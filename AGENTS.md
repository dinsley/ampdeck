# Amp Deck development

- Use Node.js 24 or newer.
- Run `npm run check` after code or manifest changes. It builds the plugin and validates the bundled manifest and layouts.
- Use `npm run watch` for local hardware iteration; it rebuilds and restarts the plugin.
- Do not publish, package, or install Marketplace artifacts without explicit approval.
- Do not use Amp or Puck trademarks or redistribute Puck artwork without confirming permission.
