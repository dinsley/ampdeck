# Security policy

## Supported versions

Until Amp Deck reaches 1.0, security fixes are provided for the latest published release.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/dinsley/ampdeck/security/advisories/new) when it is available. Include the affected version, impact, reproduction steps, and any suggested mitigation.

If private reporting is unavailable, open a repository issue requesting a private contact channel without including exploit details or sensitive information.

Please allow a reasonable period for investigation and a coordinated fix before public disclosure.
